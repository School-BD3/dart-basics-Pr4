# Практична робота № 4. Основи мови Dart

## Мета роботи

Ознайомитися з основами мови програмування Dart, навчитися працювати зі змінними, типами даних, функціями, класами, колекціями та асинхронними операціями. Отримати практичні навички розроблення, тестування та налагодження консольних програм.

## Використані технології

- **Мова програмування:** Dart
- **Dart SDK:** 3.0.0 або новіша версія
- **Система контролю версій:** Git
- **Платформа для зберігання коду:** GitHub

## Структура проєкту

```text
dart_basics/
├── bin/        # Виконувані програми
├── lib/        # Основні класи та допоміжні модулі
├── test/       # Модульні тести
├── pubspec.yaml
├── analysis_options.yaml
├── .gitignore
└── README.md
```

## Вимоги

Для роботи з проєктом необхідно встановити Dart SDK версії 3.0.0 або новішої.

Перевірити встановлену версію можна командою:

```powershell
dart --version
```

## Запуск програми

Перейдіть до каталогу проєкту та виконайте:

```powershell
dart run
```

## Перевірка коду

Для статичного аналізу коду використовується команда:

```powershell
dart analyze
```

Для запуску модульних тестів:

```powershell
dart test
```

## Виконання практичної роботи

У межах практичної роботи планується реалізувати:

1. Роботу зі змінними, типами даних і функціями.
2. Об'єктно-орієнтовану модель студентів, викладачів, курсів та університету.
3. Обробку колекцій і аналіз даних.
4. Асинхронні операції та роботу з файлами.
5. Модульні тести для перевірки правильності роботи програм.
